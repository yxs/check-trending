<h1 align="center">Check Trending</h1>

<p align="center">观察美国签证的出签趋势，并检索历年 Case Note。</p>


基于 [Checkee.info](https://www.checkee.info/) 的上报样本，主要提供以下能力：

1. **Note 全文检索** —— 2014 年至今所有带 Note 的案例（2.1 万+ ）
2. **出签效率，近期是否停滞** —— 每月 Clear / Reject 节奏与 3 月均线
3. **180 天内的出签时长分布** —— Clear 案例从 Check 到出签的天数分布（0–180 天）
