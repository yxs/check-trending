<h1 align="center">Check Trending</h1>

<p align="center">观察美国签证 221(g) / Administrative Processing 的出签趋势，并检索历年 Case Note。</p>

---

一个纯静态的网站，基于 [Checkee.info](https://www.checkee.info/) 的公开上报样本，支持：

- **趋势看板** —— 每日 Clear 节奏、7 日均线、等待时长分布、长 Check 积压，按签证类型 / 地区 / 时间筛选。
- **Note 全文检索** —— 把 2017 年至今所有带 Note 的案例（1.7 万+ 面经、补料、时间线）做成可在浏览器里直接全文搜索的语料。
